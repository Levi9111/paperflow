# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

PaperFlow executes all PDF parsing and rendering on untrusted local files. We treat memory safety and untrusted input parsing bugs with the highest priority.

If you discover a vulnerability or parser crasher:
1. Please do **not** open a public issue.
2. Email the maintainer directly at `security@paperflow.app` with a reproduction file and stack backtrace.
3. We will respond within 48 hours and coordinate a coordinated disclosure release.
